### RentMate 🏡

- A responsive rental property finder built using HTML, CSS, and JavaScript. RentMate helps users search for rental homes by location, property type, and budget.


### ✨ Features

- 🔍 Search properties by city or neighbourhood
- 🏠 Filter homes by property type
- 💰 Filter properties by monthly rent
- ↕️ Sort properties by rent
- ❤️ Save and view favourite homes
- 📝 View property details and listing previews
- 📱 Responsive design for desktop and mobile devices


### 🛠️ Tech Stack

- HTML5 — Application structure
- CSS3 — Styling and responsive layout
- JavaScript — Application logic and interactions
- Local Storage — Saving favourite properties

### 🚀 Getting Started

1. Clone the repository
```bash
   git clone https://github.com/Anjali-Sanodiya/RentMate_Frontend_Project.git
```
2. Open the project
```bash
Open the project folder in Visual Studio Code.
```
3. Install dependencies
```bash
   npm install
```
4. Run the application
```bash
   npm run dev
```

### 🏠 Demo Data

- This project includes sample rental properties in Bhopal, Indore, Pune, Bengaluru, and Delhi. Favourite homes are saved in browser Local Storage, and property submissions are previews only.
